💼 我的项目

以下是我参与或独立完成的一些项目，涵盖全栈开发、移动端、AI应用等多个领域。

携程训练营 · 酒店AI客服系统

时间： 2026/02 - 2026/04
角色： 全栈工程师
技术栈： SpringBoot · Vue 3 · Android · 高德地图 · 智谱AI GLM-4 · JWT · MySQL · Redis

基于 SpringBoot + Vue 3 构建的酒店预订全栈系统，集成高德地图与智谱AI GLM-4，实现酒店搜索、地图定位与AI智能客服。

核心亮点：

  • 前端集成高德地图API，实现酒店地理位置精准选择与可视化展示
  • Android客户端使用 Retrofit + OkHttp 封装网络层，实现 ViewPager2 + TabLayout 轮播图与多Tab酒店分类展示
  • 后端基于 SpringBoot + MyBatis-Plus 搭建高性能服务端，独立设计酒店、房型、订单等10+张核心数据表
  • 集成智谱AI GLM-4接口开发AI酒店助手，实现浮动按钮与聊天对话框，提供智能预订建议与流式对话交互
  • 实现基于JWT的统一身份认证与授权方案，封装Map类型统计信息返回，优化Android端数据展示效率

大白AI心理陪伴助手

时间： 2025/12 - 2026/04
角色： 全栈工程师
技术栈： Vue 3 · Capacitor · 腾讯混元AI · AI图像识别

基于 Vue 3 + Capacitor 构建的跨端心理健康应用，集成腾讯混元AI实现拍照情绪检测与智能心理咨询，为用户提供情绪管理与AI陪伴服务。

核心亮点：

  • 开发AI拍照情绪检测模块，用户拍照后调用AI接口实时分析情绪状态，生成个性化心理建议与干预方案
  • 基于Vue 3构建APP界面，实现心情记录、树洞对话、情绪日历等核心功能，使用Capacitor打包为跨端应用
  • 封装移动端API签名认证机制，解决腾讯混元AI接口在移动端的调用稳定性问题，保障AI服务可用性

字节跳动训练营 · 剪映团队

时间： 2025/11 - 2025/12
角色： 客户端开发
技术栈： Kotlin · Android · OpenGL · 图片处理 · 模块化架构

基于Kotlin开发的Android原生图片编辑App，负责图片裁剪、滤镜处理与效果模块，采用OpenGL实现高性能图像渲染。

核心亮点：

  • 使用Kotlin开发图片裁剪、滤镜和效果处理模块，利用OpenGL构建滤镜引擎，确保图处理不卡顿
  • 优化大图处理时的内存占用与GC频率，实现流畅的动态UI交互与实时预览
  • 采用模块化架构将UI、业务逻辑和数据层清晰分离，提升代码可维护性与扩展性

电商平台后端

角色： 后端开发
技术栈： SpringBoot · MyBatis · MySQL · Redis

仿得物电商系统的核心业务后端，涵盖商品管理、订单处理等核心模块。

核心亮点：

  • 基于 SpringBoot + MyBatis 构建服务端，独立设计并实现商品、订单、支付等核心业务模块
  • 针对高并发场景，引入 Redis 缓存机制，有效缓解数据库压力，防止超卖现象

货比三家 · 智能比价系统

时间： 2025/01 - 2025/06
角色： 全栈工程师
技术栈： Python · requests · Flask · MySQL · ECharts · AI视觉 · OCR

基于Python爬虫与AI视觉技术构建的智能比价系统，支持多平台商品价格抓取、历史趋势追踪、降价提醒与AI智能推荐筛选。

  • 集成通用物体识别API实现拍照识物功能，结合OCR提取商品信息，降低用户搜索门槛

Smart Price AI拍照识物购物助手

时间： 2026/05 - 2026/06
角色： 全栈工程师
技术栈： Flutter FastAPI Python 火山引擎Doubao VLM SSE SQLite dHash

面向C端消费者的AI拍照识物购物助手，基于Flutter与FastAPI构建，集成大模型视觉能力实现商品识别、智能导购与跨平台比价。

核心亮点：

  • 基于Flutter构建跨端App，实现拍照识物、多目标气泡标签标注、AI导购聊天等核心功能，使用CustomPainter完成扫描线与连接线动画
  • 基于FastAPI搭建后端服务，设计AI任务编排Pipeline，集成火山引擎Doubao VLM实现图像识别与LLM对话生成
  • 实现SSE流式AI对话，后端StreamingResponse配合前端逐字渲染，支持决策卡片动态生成
  • 基于dHash感知哈希实现图片识别缓存，二次识别响应<0.1秒，较首次调用提升99%
  • 设计JSON Schema约束与容错回退机制，确保大模型稳定输出结构化数据
