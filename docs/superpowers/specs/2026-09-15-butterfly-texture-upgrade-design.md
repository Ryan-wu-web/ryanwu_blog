# Butterfly 第二轮质感升级设计

## 目标

在不改变现有内容、页面结构、图片和 Butterfly 主题源码的前提下，将现有深色铜棕视觉从“基础深色主题”提升为更统一、更有层次的编辑式个人博客。所有改动必须零新增依赖、可独立撤销、兼容桌面和移动端。

## 已批准的视觉方向

- 保持当前深色铜棕主色与现有头图。
- 使用暖黑表面、低对比铜色细线、轻微内高光和克制阴影增加材质层次。
- 以细密噪点和编辑式分隔线作为唯一视觉特征，不加入粒子、强发光、漂浮组件或连续动画。
- 优先改善首页文章卡片、侧栏卡片、文章正文、代码块、标签组件和页脚。

## 架构与边界

- `_config.butterfly.yml` 只启用 Butterfly 现有能力：深色代码块、Mac 样式、Series、Mermaid，并通过 `inject.head` 加载自定义 CSS。
- `source/css/texture-upgrade.css` 保存所有视觉覆盖；不修改 `themes/butterfly/`，避免未来主题升级冲突。
- 不修改文章内容、不引入测试文章、不安装 npm 包、不启用 PJAX、Vanta、APlayer 或其他运行时组件。

## 组件设计

### 页面表面

为正文卡片和侧栏卡片增加暖黑渐变表面、低透明铜色边框、顶部细线和轻微内高光。悬浮只上移 2px，且遵循 `prefers-reduced-motion`。

### 阅读排版

正文增加舒适行高与段落间距；标题使用铜色细分隔线；链接、选中文本、引用块、Note、Tabs、Gallery 和 Series 使用同一组铜棕设计变量。

### 代码与图表

代码块切换为 Butterfly `darker` 主题并启用 `macStyle`。Mermaid 使用深色主题并允许 Markdown 代码块书写；Series 开启但不影响未声明系列的旧文章。

### 页脚与细节

将当前大面积浅铜页脚收敛为深色暖黑渐变，仅用细线和文字高光保留品牌铜色；统一分页、滚动条、目录激活态和图片边框。

## 兼容性与回滚

- 移动端减少阴影、禁用卡片位移并缩小圆角。
- 亮色模式尽量保持 Butterfly 默认，仅应用通用品牌色，不强制改为深色。
- 回滚方式：切换回 `main`；或移除 `inject.head` 样式引用、恢复四项配置并删除 `source/css/texture-upgrade.css`。

## 验收标准

1. `npm run build` 成功，无 Hexo 配置错误。
2. 首页、文章页、归档页桌面截图无布局溢出或文字对比问题。
3. 移动端首页和文章页无横向滚动。
4. 自定义 CSS 只从 `source/css/texture-upgrade.css` 注入，主题目录无修改。
5. `main` 仍指向发布版本 `76d08a3`，实验改动只存在于 `codex/texture-upgrade-v2`。
