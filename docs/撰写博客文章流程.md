# 撰写博客文章流程

> 适用于 Ryanwu 的 AI / 技术 / 生活博客。我们共同完成文章，你不需要先独立写完初稿。

## 1. 开始方式

以后只需要说：**“我们写一篇文章。”** 然后选择一种方式：

- **给选题**：提供一个主题、问题或大致观点；
- **给素材**：提供语音转写、截图、链接、笔记、经历片段或 Markdown 初稿。

## 2. 协作分工

- **Ryanwu**：提供真实经历、核心观点和最终判断；
- **AI**：负责必要追问、资料研究、文章结构、草稿、配图、文件落地和检查；
- **共同验收**：确认文章是否准确、是否像 Ryanwu、视觉是否合适。

不得编造个人经历、数据或无法验证的事实。技术文章优先使用官方资料和原始来源；生活文章保留真实感，不强行写成 SEO 长文。

## 3. 默认流程

```text
选题或素材
  → blog Skill 判断文章类型与写作方式
  → blog-write 深度写作，或轻量整理生活日志
  → 共同确认结构和观点
  → 创建 Markdown 与媒体目录
  → 完成正文、封面和配图
  → 内容检查与本地预览
  → Ryanwu 最终确认
  → 明确说“发布”后提交并推送
  → GitHub Actions 自动部署到 ryanwu.cn
```

技术分析、AI 和行业观察默认采用完整研究流程；工作复盘按需研究；生活日志采用更轻的整理方式。

## 4. 项目命令

在 `ryanwu_blog` 项目中运行：

```powershell
npm run post:new
npm run content:check
npm run preview
npm run prepublish:check
```

正式发布仅在 Ryanwu 明确说 **“发布”** 后执行：

```powershell
python tools/publish.py
```

Markdown 是唯一内容源。文章位于 `source/_posts/`，媒体位于 `source/images/posts/<post-slug>/`。

## 5. 最简单的使用方式

```text
我们写一篇文章。
选题/素材：……
我最想表达的是：……
```

其余步骤由我们在对话中共同完成。
